# Fundamentals of Python Programming – Practice Assignment

This repository contains my completed practice assignments for Sessions 1–10 of **Fundamentals of Python Programming**.

Each session is organised in a separate Jupyter Notebook and contains the assigned practice questions, code execution, supplied test runs, outputs, and short explanations.

## What I Practised

Across the ten sessions, I worked with:

- Python variables, expressions, and operators
- Numeric types and arithmetic operations
- Strings and text processing
- Lists and nested lists
- Dictionaries and key-value mappings
- Tuples, files, and mutability
- Assignment, identity, equality, and unpacking
- Conditional logic and Boolean testing
- Loops, accumulators, `break`, and iteration
- Iterators, generator expressions, and comprehensions

## My Approach

For each practice question, I:

1. Read and understand the problem.
2. Predict the expected result before running the code.
3. Write and execute the Python solution.
4. Test the supplied second run or edge case.
5. Compare the outputs and explain what changed.
6. Record a short video explanation of the solution.
