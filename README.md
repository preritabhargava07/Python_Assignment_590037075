This repository contains my solutions to the practice laboratory questions from Session 1: Python Basics.

## What I am practising

- Variables and assignment
- Arithmetic operators
- Comparison operators
- Operator precedence
- Floor division and modulus

## Approach

For each question, I will:
1. Understand the problem.
2. Predict the expected result.
3. Write and execute the Python code.
4. Test the supplied second run.
5. Explain the output and what changes between the two runs.
